# Шахмашки

Браузерная игра для второго тура Azyon Incubator 2026. Два режима: авторский гибрид шахмат и шашек и классические шахматы.

## Возможности

- Игра вдвоём на одном устройстве или против простого бота за чёрных.
- Подсветка допустимых ходов, история, отмена хода, разворот доски.
- Шах, мат, пат, ничьи. Новая игра с защитой от случайного сброса.
- Выбор фигуры при превращении. Автосохранение в браузере.
- Адаптивный интерфейс на русском языке.

## Правила гибрида

Восемь шашек вместо пешек на втором и седьмом рядах, включая клетки обоих цветов. Остальные фигуры стоят и ходят как в шахматах. Цель — мат королю.

Шашка ходит на одну клетку по диагонали вперёд, бьёт прыжком в обе стороны. Доступное взятие шашкой обязательно, если вся серия не оставляет своего короля под шахом. Выполняется полная серия, выбор направления свободный. В этой авторской версии взятые фигуры убираются сразу.

На последней линии можно выбрать дамку, ферзя, ладью, слона или коня. Дамка передвигается по диагонали на любое расстояние, перепрыгивает одну чужую фигуру и может приземлиться на любой свободной клетке за ней. При превращении в дамку серия продолжается, при выборе шахматной фигуры ход заканчивается.

Короля нельзя съесть. Шашка атакует короля только при свободной клетке за ним. Ход не может закончиться под шахом. Рокировка сохраняется. Ничьи: пат, троекратное повторение, 50 полных ходов без взятия и хода простой шашки, только короли на доске.

В классическом режиме используется chess.js со стандартными правилами, в том числе взятием на проходе.

## Разработка

Node.js 20.19+ или 22.12+.

```sh
npm install
npm run dev
npm test
npm run build
```

Готовая сборка — `dist/`. Хостинг: любой статический веб-сервер; команды сборки на сервере: `npm run build`, каталог публикации: `dist`.

## Проверка

15 автоматических проверок: специальные шахматные ходы, мат и пат, шашечные серии и превращение, шах от шашки, рокировка, обязательное взятие, безопасность короля. Случайные партии проверяют целостность состояния и отмену хода.

В браузере отдельно проверены первый ход, подсветка, восстановление после перезагрузки, отмена и мат в классическом режиме. Мобильная ширина проверена на отсутствие горизонтального переполнения.

## Ограничения

Бот любительский: предпочитает взятия и превращения, не просчитывает глубокие варианты. Онлайн-мультиплеера нет; двое играют на одном устройстве. Публичную ссылку нужно получить публикацией сборки на доступном хостинге.
